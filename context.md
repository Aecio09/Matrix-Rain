The goal of this activity is to implement a Matrix Rain effect using any framework and coding agent of your choice. You may work individually or in pairs.

The first basic implementation will probably be something like a green text rain effect on a black background, but you are free and encouraged to explore more advanced implementations, such as:

- using different colors for the text;
- using different fonts;
- using different characters for the rain;
- using glows or other visual effects;
- using fade-in and fade-out effects;
- using different speeds for the rain;
- etc

Probably, the most important part of this activity is to document the development process in a file named `BUILD_LOG.md`. You should keep it updated throughout development, recording every relevant development interaction, decision, implementation step, bug, or correction. Each entry should contain:

- Prompt / Request
- Decision Summary
- Actions Performed
- Result
- Problems / Errors
- Fixes Attempted

Also, you should be able to explain not only what the application does, but also how it was implemented, which decisions were made by the coding agent, which problems occurred during development, and how those problems were solved.

## Restrictions

1. The first implementation should use only CPU-based rendering. You may later explore GPU-based rendering, so you can compare the performance of both approaches, identifying the bottlenecks and the advantages of each one. You may also explore other rendering techniques, such as using WebGL or Canvas, but you should document your decisions and the reasons behind them in `BUILD_LOG.md`.

2. You may use any programming language, framework, or library you want, but you should document your decisions and the reasons behind them in `BUILD_LOG.md`.

3. Your Matrix Rain should be "truly random", meaning that the characters, colors, fonts, and speeds should be randomly generated (even though truly randomicity is unlikely to be achieved). This is meant to limit you from using a fixed set of characters, colors, fonts, speeds, images, gifs, or other assets.
